# Phyllosedis Platform

Многомодульная платформа, построенная на базе Spring Boot 3.3.4 и Java 21. Проект спроектирован по принципу **модульного монолита** с четким разделением бизнес-доменов, что подготавливает архитектуру к будущему разделению на независимые микросервисы.

## Архитектура проекта

Проект организован в виде монорепозитория, управляемого Maven. Каждый бизнес-домен разделен на два изолированных подмодуля: **API** (контракты и DTO) и **IMPL** (бизнес-логика).

```text
backend/
├── pom.xml (Родительский POM, управление зависимостями)
├── app/ (Точка входа, сборка монолита)
├── banking/
│   ├── banking-api/ (Интерфейсы и DTO банкинга)
│   └── banking-impl/ (Реализация логики банкинга)
├── messenger/
│   ├── messenger-api/ (Интерфейсы и DTO мессенджера)
│   └── messenger-impl/ (Реализация логики мессенджера)
└── social/
    ├── social-api/ (Интерфейсы и DTO соцсети)
    └── social-impl/ (Реализация логики соцсети)
```

## Управление версиями (SemVer & Git Flow)
- Проект использует централизованное управление версиями через родительский `pom.xml`.
- Разработка ведется в изолированных ветках фич (например, `banking/feature/feature-name`).
- Каждая папка домена содержит свой собственный `developer-changelog.md` для изоляции истории изменений.

## Сборка и запуск

Сборка всего проекта выполняется исключительно из корневой директории:
```bash
mvn clean package -DskipTests
```
Готовый исполняемый Fat-JAR будет находиться в папке `app/target/`.
