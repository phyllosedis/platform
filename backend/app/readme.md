# Модуль `app`

## Назначение модуля
Модуль `app` является **главной точкой входа** и агрегатором всего модульного монолита. Он отвечает за склейку независимых бизнес-доменов платформы воедино, конфигурацию сквозных процессов и запуск веб-сервера.

## Основные функции
1. **Точка запуска:** Содержит главный класс `PlatformApplication` с аннотацией `@SpringBootApplication`.
2. **Конфигурация инфраструктуры:** Настройка глобального сканирования пакетов (`scanBasePackages = "ru.phyllosedis.platform"`), благодаря чему Spring видит бины из соседних `impl`-модулей.
3. **Маршрутизация (REST-контроллеры):** Принимает HTTP-запросы из внешнего мира и делегирует их выполнение в интерфейсы `api`-модулей.
4. **Сборка дистрибутива:** С помощью `spring-boot-maven-plugin` упаковывает весь скомпилированный код платформы в единый исполняемый файл.

## Зависимости
Модуль напрямую зависит от:
- `spring-boot-starter-web` (для поднятия Tomcat и работы REST)
- Всех модулей **`*-api`** (чтобы знать контракты для контроллеров)
- Всех модулей **`*-impl`** (чтобы Spring Boot мог внедрить реализации в рантайме)
