# Бизнес-домен: Messenger

Данный модуль отвечает за всю коммуникационную составляющую платформы: обмен мгновенными сообщениями, управление чатами (диалогами и группами), а также статусами доставки и прочтения. Проектирование домена разделено на два подмодуля для обеспечения слабой связанности компонентов.

## Подмодуль `messenger-api`
**Назначение:** Определение публичного контракта системы обмена сообщениями.
- Не содержит бизнес-логики и является ультра-легковесным.
- Не зависит от тяжеловесных модулей Spring Framework.
- Содержит контракты интерфейсов (например, `ChatService`, `MessageService`) и структуры данных (DTO) для передачи текстовых и медиа-пакетов.
- Используется модулем `app` для построения контроллеров, а также может подключаться другими сервисами платформы (например, `banking` для отправки сервисных уведомлений в чат).

## Подмодуль `messenger-impl`
**Назначение:** Внутренняя реализация логики мессенджера.
- Содержит конкретную бизнес-логику обработки, валидации, маршрутизации и сохранения сообщений.
- Зависит от базового стартера `spring-boot-starter` для управления жизненным циклом компонентов (`@Service`, `@Component`).
- В будущем именно здесь будет настроена интеграция со слоем хранения данных, а также трансляция событий в брокер сообщений (Kafka) для обеспечения real-time обмена.
