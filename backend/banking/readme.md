# Бизнес-домен: Banking

Данный модуль инкапсулирует в себе всю логику финансовой платформы (счета, балансы, транзакции). Разделен на два подмодуля для обеспечения слабой связанности.

## Подмодуль `banking-api`
**Назначение:** Определение публичного контракта сервиса.
- Не содержит бизнес-логики.
- Не зависит от Spring Framework (ультра-легковесный).
- Содержит DTO (`AccountBalanceDto`) и интерфейсы сервисов (`BankingService`).
- Предназначен для подключения другими модулями платформы, которым необходим доступ к возможностям банкинга.

## Подмодуль `banking-impl`
**Назначение:** Реализация бизнес-логики банкинга и интеграция с инфраструктурой.
- Реализует интерфейсы из `banking-api`.
- Зависит от базового `spring-boot-starter` для объявления Spring-бинов (`@Service`).
- В будущем отвечает за интеграцию с базой данных (PostgreSQL / Apache AGE).
