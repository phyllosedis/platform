# Бизнес-домен: Social

Данный модуль инкапсулирует в себе функционал социальной сети платформы. Его основная задача — управление профилями пользователей, их социальными связями (друзья, подписки), формирование ленты активности и обработка графовых зависимостей между сущностями.

## Подмодуль `social-api`
**Назначение:** Публичный интерфейс и контракты социального графа.
- Полностью изолирован от деталей реализации и хранения данных.
- Хранит интерфейсы управления социальным контекстом (например, `ProfileService`, `FriendshipService`) и DTO для передачи данных профиля и списков связей.
- Подключается модулем `app` для реализации REST-эндпоинтов, а также дочерними `impl`-модулями других доменов для верификации прав доступа и связей между пользователями.

## Подмодуль `social-impl`
**Назначение:** Реализация социальной логики и графовых вычислений.
- Инкапсулирует алгоритмы поиска по графу друзей, построения ленты рекомендаций и управления профилями.
- Использует аннотации Spring (`@Service`, `@Repository`) для связывания компонентов контекстом приложения.
- Этот модуль имеет стратегическое значение для интеграции с расширением **Apache AGE**, так как социальные связи идеально ложатся на графовую модель данных (узлы-пользователи и ребра-связи).
